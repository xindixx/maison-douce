# Maison Douce

An online store for feminine, French-inspired pajamas, designed for women aged 20–35 who want comfort and beautiful design.

## Files
- `index.html`: the page content
- `style.css`: colours, fonts and layout
- `script.js`: products, the shopping bag and the newsletter form

## Editing products
Open `script.js` and edit the `products` list (names, colours, prices).
